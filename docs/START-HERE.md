# START HERE

Use this checkpoint before beginning work in NovaLab Platform.

## Startup checklist

- Read the latest relevant entry in [`docs/sessions`](sessions/).
- Run `git status` and identify existing changes before editing.
- State today's objective and keep the work scoped to it.
- Read the standards, architecture notes, and runbooks relevant to the change.
- Verify the target environment before running Terraform, Kubernetes, or Compose commands.
- Confirm that credentials, variable files, state, plans, and other secrets will remain uncommitted.
- Prefer validation, planning, and dry-run operations before changing infrastructure.
- Record decisions or operational discoveries in the appropriate repository documentation.
